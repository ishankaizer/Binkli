# Textures

Drop your **real** ripped-paper / mixed-media texture images here (PNG or WebP,
transparent edges where relevant). These are used as-is — never redrawn as
vector shapes.

Suggested naming so the code can find them:

- `paper-divider.png`   — the ripped-paper section divider (the one that used to
                          get turned into a flat 2D drawing)
- `paper-edge.png`      — torn edge between canvas and the effects panel
- `paper-bg.jpg`        — full-bleed paper background texture (optional)
- `tape-1.png`, `tape-2.png` — washi / masking tape strips (optional)

Reference them in code as `/textures/paper-divider.png` (Vite serves `public/`
from the site root).
